# Engenharia de Prompt - Fundamentos

## Comparação entre Prompt Genérico e Prompt Estruturado

### Prompt Genérico

**Pergunta:**
O que é Machine Learning?

**Resposta:**
Machine Learning é uma área da Inteligência Artificial que permite que computadores aprendam a partir de dados sem serem explicitamente programados para cada tarefa. Os algoritmos identificam padrões nos dados e utilizam esse conhecimento para fazer previsões ou tomar decisões.

---

### Prompt Estruturado

**Prompt:**
Atue como um professor de tecnologia. Explique o que é Machine Learning para um iniciante, utilizando uma analogia com esportes e apresentando a explicação em dois parágrafos.

**Resposta:**
Machine Learning pode ser comparado ao treinamento de um atleta. Assim como um jogador melhora seu desempenho ao praticar várias vezes e aprender com os próprios erros, um algoritmo de Machine Learning melhora sua capacidade de fazer previsões ao analisar grandes quantidades de dados.

Por exemplo, um treinador observa partidas passadas para identificar estratégias vencedoras. Da mesma forma, um sistema de Machine Learning analisa dados históricos para encontrar padrões e utilizá-los em situações futuras, tornando suas previsões cada vez mais precisas.

---

## Análise Crítica

A resposta gerada pelo prompt estruturado foi mais útil porque definiu claramente o papel da IA, o público-alvo, o contexto e o formato desejado. Isso reduziu a ambiguidade e produziu uma explicação mais didática e fácil de entender. A estrutura permitiu obter uma resposta mais adequada às necessidades do usuário em comparação com o prompt genérico.
